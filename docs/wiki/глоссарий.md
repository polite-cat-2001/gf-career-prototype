# Глоссарий

Имена предметной области проекта. Термин берётся отсюда для заголовков задач, имён тестов и
формулировок гипотез. Разрешил новый термин — допиши сюда.

## Основные

| Термин | Определение |
|---|---|
| Менеджер | Игрок-тренер в режиме карьеры. В UI и коде — «менеджер»; «тренер» не используем |
| Карьера | Один сейв: менеджер, клуб, мир, сезоны, журнал действий |
| Канон | Read-only данные мира: клубы, игроки, рейтинги, лиги. Собирается в `canon.db` |
| Рейтинг (OVR) | Показываемая сила игрока 0–99 из `ratings-generator`; отдельного атрибута нет |
| Потенциал (pot) | Жёсткий потолок OVR; до отчёта скаута показывается вилкой |
| Сейв | JSON-файл карьеры в `saves/`; хранит дельту и сыгранный сезон (`schedule`, `results`) |
| Фикстура | Эталонный сценарий `seed + actions → snapshot` для тестов и переноса в C++ |
| Мир | Все страны и лиги; вне страны карьеры симулируется упрощённо (результаты, таблицы, бомбардиры) |
| Календарь | Double round-robin лиги: каждый клуб играет с каждым дома и в гостях; даты — раз в неделю |
| Тур | Один круг матчей календаря; `play` доступен в день матча, симулирует весь тур и переносит дату на день после матча |
| Перемотка | Визуальный шаг времени по 1 дню в секунду; каждая остановка сохраняется серверным `advance`, дальше дня матча не уходит |
| Следующий сезон | После финального тура: итог в журнал, `season_start` +1 год, новый календарь и пустые результаты |
| Таблица | Очки/разница/место по результатам туров; сортировка — очки, разница, забитые, имя |
| Форма | До пяти последних матчей клуба в виде W/D/L для виджета «Далее» |
| Дивизион | Уровень лиги внутри страны; 1–2 в прототипе, обмен 3↑/3↓ |
| Кубок | Генерируемый национальный одноматчевый нокаут всех клубов страны с баями |
| Легионер | Игрок, чьё гражданство не совпадает со страной лиги; лимит — 5 в стартовом XI |
| Кондиция | Усталость + травма + дисквалификация; полная — только в стране карьеры |
| Усталость | 0–100 (100 — свежий): −35 за матч, +10 в день |
| Потенциал позиции | Привычка к позиции 0–100%; штраф по матрице схожести позиций |
| Цель | Обязательство руководства: 12 = 4 категории × 3 срочности |
| Доверие совета | %; растёт/падает от целей, долга и места; <20% два месяца → увольнение |
| Удовлетворённость фанатов | %; двигается результатами и спортивными/имиджевыми целями |
| Подписчики | Аудитория клуба; производная от фанатов и звёздности состава |
| Репутация менеджера | 0–100; близость к запланированному результату, гейтит вакансии |
| Шортлист | Список игроков «на карандаше»; переживает смену клуба |
| Предконтракт | Договор с игроком за 6 месяцев до истечения контракта |
| Аренда | fee + доля зарплаты, полсезона/сезон; выкуп — переговорами по ходу, досрочно не разрывается |
| Скаут | Слот 1–3; статы «скорость» и «качество»; отчёт 3–10 дней |
| Академия | 20 мест для юниоров; авто-рост к потенциалу, промоушен в основу в 16 лет |
| Youth intake | Ежегодное пополнение молодёжи у клубов ИИ (март) |
| Товарняк | Предсезонный матч: фитнес, деньги, развитие; в статистику сезона не идёт |
| Предсезонный турнир | 8 клубов, 3 предложения; международный или национальный по силе клуба |
| Вертикальный срез | Первая играбельная версия: полная петля карьеры с минимальной глубиной |
