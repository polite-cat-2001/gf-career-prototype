# Визуальный стиль

Статус: **миграция начата**. Решения зафиксированы 2026-11-04. Источник визуального языка —
соседний `../gf-ui-prototype` (его `docs/wiki/визуальный-стиль.md` и `ui-система.md`). Figma остаётся
референсом компоновки, но не визуальной правды.

Страница отвечает на вопрос «как выглядит». Как устроены экраны и фокус — [[архитектура]].

## Решение

| Вопрос | Выбор |
|---|---|
| Основа | **Светлая на всех экранах**, включая матч, день матча и итоги сезона |
| Выбор | Полная инверсия заливки: светлая плитка → тёмно-индиго с лаймовым заголовком |
| Фон | Приглушённый кадр стадиона с медленным зумом/паном; поле матча остаётся зелёным |
| Палитра | Магента — служебные линии, лайм — только фокус; win/loss/warn — приглушённые метки |
| Форма | Острые углы, швы 10px, без бордеров и скруглений |
| Типографика | Barlow Condensed для заголовков, Inter для текста; **ничего мельче 16px** |
| Композиция | Бенто: крупный тайл + компактные; страница не скроллится |

## Формула

ТВ-интерфейс для геймпада. Светлые плитки лежат на движущемся стадионе и образуют одну плиту,
разделённую швами. Ровно один элемент выбран, и выбор — это переворот заливки, а не подсветка.
Магента отмечает «сюда можно нажать», лайм — «ты сейчас здесь». Крупный капсовый заголовок
сверху-слева, арт или глиф снизу-справа, хром по краям safe area, контекстная легенда внизу-слева.

## Геометрия

- Ширина панели — `min(1480px, 100%)`; safe area — 44px по бокам.
- Хром компактный: полоса пути и главные табы — `--chrome-h` = 38px; вторичные табы и заголовки
  разделов держат ту же высоту.
- Сетка — 4 колонки, `gap: 10px`, `border-radius: 0`, бордеров нет.
- Один тайл в разделе крупный (`2×2`), остальные — `1×1` или `2×1`.
- Панель и полоса табов выровнены по левому краю и ширине: табы — шапка панели.
- Страница не скроллится: длинные списки и таблицы скроллятся внутри своих панелей.
- Всё содержимое экрана помещается в 1366×768 и 1920×1080.

## Анатомия плитки

```
┌─────────────────────────────┐
│ ЗАГОЛОВОК                   │  ← top-left, капс, 2 строки максимум
│ подпись                     │  ← опционально, обычный регистр
│                             │
│                    [арт/глиф]│  ← bottom-right
└─────────────────────────────┘
```

- Внутренний padding — 24px.
- Текст не центрируется и не прилипает к краю.
- Арт либо стоит справа-снизу, либо его нет и работает глиф.
- Цвет глифа: на светлой плите чернильный, на выбранной — магента.

## Состояния

| Состояние | Вид |
|---|---|
| `default` | Заливка `--tile`, текст `--ink`, магентовая рейка 6px слева |
| `selected` | Заливка `--focus-fill`, текст `--focus-ink`, заголовок `--focus-mark`, глиф `--rail`; рейка исчезает |
| `disabled` | `opacity: .42`, без рейки и реакции на ввод |

- Состояний только три. `hover` не существует: мышь переводит тот же `selected`.
- Выбранная плитка приподнимается: `scale: 1.008` и сдвиг на 6px наружу от центра.
- Контраст держится на светлоте, а не на цвете.

## Палитра

```css
:root {
  --tile: rgba(245, 247, 250, 0.95);
  --focus-fill: #171b3f;
  --focus-fill-soft: #2b3157;  /* поверхность аккордеона под выбранной строкой */
  --ink: #1d2138;
  --ink-2: #5a5f78;
  --focus-ink: #f6f8fb;
  --focus-ink-2: rgba(246, 248, 251, 0.66);
  --rail: #e6236e;        /* служебные линии и рейки */
  --focus-mark: #c9f227;  /* только заголовок выбранного */

  --mark-win: #2f7d4f;
  --mark-loss: #b23a48;
  --mark-warn: #a66a00;
}
```

Правило: **магента не заливает, лайм не украшает.** Win/loss/warn живут только точками,
полосками 2–4px и мелким текстом, не заливками. Лайм остаётся за фокусом; бренд — единственное
декоративное исключение, унаследованное от прототипа.

## Типографика

- Заголовки — Barlow Condensed, 700–800, капс, трекинг около `-0.01em`.
- Текст — Inter, 400–600.
- Никаких засечек, курсива, декоративных шрифтов и моно.
- Жёсткий минимум — **16px**. Шкала: 16 — мета и легенда, 18 — подпись, 20 — строка, 24 — таб,
  32–44 — заголовок плитки, 52 — широкая плитка, 64 — крупная.
- Плотность: меньше строк на экран, внутренний скролл и пагинация вместо мелкого текста.

## Хром

| Зона | Что там |
|---|---|
| Верх-центр | Табы на главных экранах; в подменю вместо них — путь со скошенным краем |
| Верх-право | Статус/уведомления; клубная строка карьеры садится правым сегментом шапки-табов |
| Центр | Сетка плиток или список; единственное место для контента |
| Под панелью слева | Легенда управления; ниже — бренд справа |
| Низ-право | Бренд `GF CAREER` |

- В подменю табы исчезают: две конкурирующие навигации не нужны.
- Переход между экранами — fade с масштабом: 150ms наружу, 240ms внутрь.
- Легенда показывает подсказки последнего устройства.

## Экраны

| Экран | Статус | Задача |
|---|---|---|
| Старт | **переведён** | Бенто: крупный «Продолжить», «Новая игра», «Загрузить» |
| Загрузка | в очереди | Крошки + светлые строки, выбранная строка инвертируется |
| Новая карьера | в очереди | Пересборка как EA FC: крупный клуб + панель деталей, затем менеджер |
| Хаб «Центр» | в очереди | Бенто: герой-календарь, трансферы, таблица, новости, тренировка |
| Состав | в очереди | Обзор, центр составов, план, детали, номер/отпуск/суммы/переговоры |
| Трансферы | в очереди | Хаб, фильтры 4×2, результаты, центр, история, модалки |
| Скаутинг | в очереди | Сетка 3×2 + панель |
| Матч и итоги | в очереди | Светлые панели, зелёное поле, инверсия выбранного |
| Модалки | в очереди | Светлые листы на скриме, острые углы |

## Новые фичи

- Только `web/src/lib/ui/` и классы `gf-*`; легаси-токены (`--teal`, `--violet`, `--glass`,
  `--radius-*`, `--font-mono`) в новом коде не используются.
- Один фокус; hover = selected; фото только `object-fit: contain` и прижаты к низу.
- Новые экраны не добавляют собственный хром: только `AppShell` и примитивы.

## Реализация

- `web/public/stadium.jpg` — фон, скопирован из `../gf-ui-prototype`.
- `web/src/styles/theme.css` — токены, стадион, типографика, хром, плитка, фокус.
- `web/src/lib/ui/AppShell.svelte` — стадион, frame, шапка, легенда, бренд, статус.
- `web/src/lib/ui/Tile.svelte` — плитка бенто; `TabBar`, `Breadcrumb`, `Legend`, `Glyph`, `Accordion`.
- `web/src/lib/StartScreen.svelte` — первый переведённый экран; `styles/start.css` удалён.
- Фокус: `[data-nav]:focus` на `.gf-tile` даёт инверсию; строки и панели следующих экранов
  используют тот же контракт `--surface-*`.
- Легаси-экраны пока живут на старых стилях; их перевод — следующие волны.
